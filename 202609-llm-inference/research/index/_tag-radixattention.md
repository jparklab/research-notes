- [[sglang-efficient-execution-of]] — SGLang: Efficient Execution of — The original SGLang paper (Zheng et al., Stanford/UC Berkeley/SJTU, 2023-2024, arXiv 2312.07104) introduces RadixAttention, the prefix-tree KV cache reuse technique that NVIDIA Dynamo's KV router and AIBrix's routing strategies build on conceptually. RadixAttention retains (rather than discards) the KV cache of every completed generation request in an LRU-cache radix tree, using the tree for efficient prefix matching, insertion, and eviction; KV tensors are stored in a non-contiguous, page-per-token layout compatible with continuous batching, PagedAttention, and tensor parallelism, adding only negligible overhead. A cache-aware scheduling policy built on top of this radix tree improves cache hit rate by prioritizing requests whose prefixes are already resident. Combined with a compressed finite-state-machine decoder for structured outputs and API speculative execution for API-only models (e.g. GPT-4), SGLang achieves up to 6.4x higher throughput and up to 3.7x lower latency versus vLLM, Guidance, and LMQL across agent control, logical reasoning, few-shot learning, JSON decoding, RAG, and multi-turn chat workloads on Llama-7B/70B, Mistral-8x7B, and LLaVA models on A10G/A100 GPUs.
