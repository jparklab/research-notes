Critically for non-k8s feasibility: vLLM's NixlConnector operates pull-based (D reads KV blocks from P's GPU memory via one-sided RDMA READs) with LAZY, DECENTRALIZED pairing -- 'the first time D sees an unknown P engine it performs a background handshake that exchanges metadata over ZMQ, validates a compatibility hash, and bootstraps the RDMA path... Additional connector features: heterogeneous TP between P/D (D computes which remote TP rank to read and fetches the matching slice), Hybrid Memory Allocator support for SSM-hybrid architectures (Jamba/Mamba), and fault tolerance via a configurable kv_lease_duration with D-side heartbeats (P auto-frees blocks if D crashes) and a kv_load_failure_policy (fail=default, error immediately; recompute=fall back to local prefill on D).
