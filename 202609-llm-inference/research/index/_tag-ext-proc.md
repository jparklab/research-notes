Defines the wire contract between a data-plane proxy (e.g. Envoy) and the EPP over Envoy ext_proc, which the EPP MUST implement including streaming mode. Endpoint identity on the wire is purely ip:port strings, not k8s object references: the data plane can restrict the EPP to a subset via filterMetadata key envoy.lb.subset_hint / x-gateway-destination-endpoint-subset (list of ip:port); if unset the EPP selects from the InferencePool selector's endpoint set.
