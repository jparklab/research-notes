* deps: bump gateway-api-inference-extension to v1.5.0

Pin GAIE dependency to the v1.5.0 release tag instead of the previous
pseudo-version commit. Run go mod tidy to update checksums.

Signed-off-by: Etai Lev Ran <elevran@gmail.com>

* migrate: update plugins to gateway-api-inference-extension v1.5.0 API

Adapt all plugin code and tests to the breaking changes in v1.5.0:

- PrefixCachePluginType renamed to PrefixCacheScorerPluginType
- Prompt changed from string to struct; use .Raw field for string access
- prefix.New() no longer takes a Config argument
- SchedulingContextState/BlockHash/ServerID removed; prefix cache hits
  are now communicated via endpoint attributes (PrefixCacheMatchInfoKey)
- prefix.Plugin.PreRequest removed
- Add test/utils/igw wrapper to restore DeleteObjects removed from
  upstream test/utils in v1.5.0

Signed-off-by: Etai Lev Ran <elevran@gmail.com>

* fix(e2e): remove prepareDataPlugins feature gate from EPP configs

The prepareDataPlugins feature gate was graduated and removed in
gateway-api-inference-extension v1.5.0. Referencing it in EPP
configs causes a hard startup failure, putting the EPP pod into
CrashLoopBackOff and blocking all e2e tests.

Signed-off-by: Etai Lev Ran <elevran@gmail.com>

* chore: fix import grouping in PR-changed files

Apply consistent 3-group import ordering across all files changed in
this PR: std → external (including llm-d-kv-cache) → llm-d-inference-scheduler.
Remove unnecessary aliases (logutil, fwkdl, and redundant self-aliases
where the alias equals the package name).

Signed-off-by: Etai Lev Ran <elevran@gmail.com>
